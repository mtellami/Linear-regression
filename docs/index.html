02 / Linear regression

The model is a straight line. Training finds its intercept and slope.

ŷ = θ₀ + θ₁x

θ₀ is the estimated price at zero mileage; θ₁ is the change in price per kilometer. ŷ is the predicted price.

03 / Residuals and the cost function

A residual here is the predicted price minus the actual price. Gradient descent does not classify individual residuals as acceptable or unacceptable. It minimizes the aggregate squared error.

Model B is better because its overall cost is lower, even if some individual predictions are still wrong.

J(θ₀, θ₁) = (1 / 2m) Σ (ŷᵢ − yᵢ)²

m is the number of observations. Squaring prevents cancellation and penalizes large errors. Dividing by m averages the squared errors; the factor 1/2 simplifies differentiation.

Why optimal does not mean accurate

Two cars at 100,000 km cost 9,000 and 3,000. Their best shared squared-error prediction is 6,000, despite both errors being 3,000. Mileage alone cannot distinguish them.

04 / Gradient descent

The gradient tells us how cost changes as parameters change. Move opposite the gradient to reduce cost. The following simplified example has one parameter and a known minimum.

J(θ) = (θ − 6)²   |   J′(θ) = 2(θ − 6)
Cost
Derivative
Direction
Learning rate = 0.2. Negative derivative moves right; positive derivative moves left.

In the actual project, compute both gradients using the same current parameters, then update them simultaneously:

tmpθ₀ = (α / m) Σ (ŷᵢ − yᵢ)
tmpθ₁ = (α / m) Σ (ŷᵢ − yᵢ)xᵢ
θ₀ ← θ₀ − tmpθ₀   ;   θ₁ ← θ₁ − tmpθ₁

Learning rate (α)

A small rate converges slowly; an appropriate rate converges steadily; an excessive rate can overshoot and diverge.

When should training stop?

The subject does not prescribe a stopping rule. Options include a fixed iteration count, negligible cost improvement, a sufficiently small gradient, or a target cost if achievable. A low gradient does not imply every residual is small.

09 / Explaining the project

We implement simple supervised linear regression from scratch. Using car mileage and prices, we initialize two parameters to zero and repeatedly adjust them using gradient descent to minimize squared prediction error. We save the learned parameters and use a separate program to predict prices from new mileage values.
